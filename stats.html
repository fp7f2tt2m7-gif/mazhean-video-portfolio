PORTFOLIO INSIGHTS

了解作品，
是怎样被看见的。

查看访问来源、停留和作品观看表现，决定下一次优化什么。

登录百度统计并查看数据 ↗

数据在百度统计后台显示，需要登录有该站点权限的账号。

01 / 来源

链接有没有被打开？

在网站概况查看访客数、浏览量和平均访问时长；按带标记的入口链接区分不同投递来源。

02 / 停留

是略过，还是认真看？

查看前台停留达到 10、30、60、120 秒的次数，以及各段工作经历被选择的次数。

03 / 作品

哪些作品更有吸引力？

比较封面点击、实际起播、有效观看时长和观看进度。点击多但观看短，可以继续检查封面、开头和内容匹配。

SHARE WITH A SOURCE

给投递链接加一个来源标记。

使用渠道或公司代号，如 boss、company_a。标记区分链接来源，不识别 HR 的真实身份。

支持 1–32 位英文字母、数字、下划线和短横线。

READ THE REPORT

在后台这样查看。

进入“访问分析 → 事件分析”，按下表筛选类型和操作，再按标签比较来源或作品。

想了解什么类型 / 操作怎么看
投递来源访问portfolio / visit按标签区分 boss、company_a 等来源。
前台停留portfolio / engaged-10s、30s、60s、120s比较不同停留档位。切到后台的时间不累积。
经历选择portfolio-project / select标签包含来源和公司，比较各段经历的选择次数。
视频点击排行portfolio-video / play按事件总数排序；标签包含来源和视频标题。
实际播放portfolio-video / started区别于点开封面，视频真正开始播放才记录。
有效观看时长portfolio-video / watch-seconds事件价值为秒数；在关闭、切换或离开页面时记录。暂停、缓冲、后台时间不累积。
有效观看进度portfolio-video / watched-25pct、50pct、75pct按实际看过的不同片段计算，拖动或重复看同一段不增加覆盖比例。
看至结束portfolio-video / completed实际观看至少四分之三且播放结束，才记一次。
简历兴趣portfolio-resume / open、download分别记录打开与下载入口的点击。

完整前台停留片段也以 portfolio / visible-seconds 记录秒数。统计有更新延迟，离开页面上报可能受浏览器与网络影响；短时趋势配合视频点击、停留档位一起看。没有投递或曝光数量时，访问量不能直接称为链接点击率。
